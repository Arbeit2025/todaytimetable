# きょうの時間割ボード（todaytimetable）

週間時間割を登録しておくと、トップページに **Asia/Tokyo の「今日」の曜日の授業だけ** を時限順に大きく表示するボードです。着想元は NazmusSayad の college-routine（授業時間割の管理・表示）です。

## 機能

- **今日ビュー（トップページ）**：今日の曜日に対応する授業だけを、時限順に大きな文字で表示します。授業がない日は「今日の授業はありません」と表示されます。
- **授業の登録**：曜日（月〜日）、時限（1〜8限）、科目名、教室（任意）、メモ（任意）を登録できます。データは SQLite に保存されます。
- **曜日ごとの一覧・編集ページ**：曜日別に授業の一覧表示・追加・削除ができます（削除は確認ダイアログつき）。
- 「今日の授業を選ぶ」ロジックは、曜日を受け取る純粋関数 `classes_for_weekday` に分離してあり、曜日別選択と時限順ソートを単体テストで検証しています。

DB のパスは環境変数 `TODAYTIMETABLE_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- ログイン機能はなく、時間割は利用者全員で共有される1枚のボードです。個人の時間割を公開したくない場合は公開デプロイに注意してください。
- **Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。** 登録した時間割が初期化されることがある点に注意してください。
- 授業の編集は「削除して登録し直す」方式です（その場での内容変更機能はありません）。
- 祝日や臨時の休講・振替には対応していません。表示は曜日ベースのみです。
